# Team Name Core Protocol Zero

In this game, there are two players who each need to defend a power core that is providing the last
power to their desolate wasteland that they call home. They will need to defend against hordes of
ruthless enemies by using special abilities to their advantage.

# Prerequisites
In order to run this project the tool **7zip** will need to be downloaded.
1. Go to https://www.7-zip.org/
2. Download the 64-bit x64 Windows install
![7zip install](artifacts/readme%20images/7zipInstall.png)
3. Double Click the install .exe script that is downloaded and click install at your desired filepath (default is fine)
4. Once done installing close the .exe and 7zip is installed!
# Run Instuctions
### How to install the game:
1. In this repository, go to /artifacts/Builds or click https://github.com/LukeErlewein/GVSU-CIS350-Co-op-video-game/tree/main/artifacts/Builds
2. Click on The Latest Version of the Game
3. As seen in the image, click the Raw button at the top left of the file to download the file
![Github download game](artifacts/readme%20images/githubInstall.png)
4. Go to your downloads folder on your computer and locate the .7z file you just downloaded
5. Right-Click and hover over the 7-Zip options and click the "Extract files..." button, ignore the given settings and press enter!  
Do note that Windows 11 Users will have to click "Show More Options" when they intially right-click to find the 7-Zip options
6. All Set! The New Folder will contain an executable file that will run the game.

### How to Play the Game
#### Host:
1. Click the Copy OID button in the Main Menu and send the code to your friend!
2. Once Sent, feel free to press the "Host" button and wait for your friend to join.
3. The Game will start once your friend joins and a connection is established.

#### Client/Friend Joining:
1. Once the code is received, input it into the text box marked "Host OID".  
IMPORTANT: Make sure that the words "Host OID" are replaced by the lobby code received from the Host.
2. Once the host has pressed the "Host" button, press the "Join" button and wait to be connected.
3. The game will start once an internet connection is established
  
  
#### The game is now starting, heres what to expect: 
1. The host will spawn as the Fighter Character, as the Fighter  
you have abilities related to crowd control and excel at multi-target damage.  
Your Strength also allows you to pickup Power Cells to charge the Core!  
However you are unable to kill the mighty Cell Carriers, who carry the Power Cells
2. The client will spawn as the Ranger Character, as the Ranger  
you have abilities related to your Sniper Rifle and high movement capabilities for quick  
re-positioning or tactical retreats. You may not be strong enough to pickup those Power Cells  
however, your powerful rifle will certainly defeat those Cell Carriers. Work with the Fighter to defeat and collect those Power Cells
3. Your Characters Start with One Ability, Unlocked the other 3 at 25, 50, and 75 Percent Core Charge Respectively.  
However, as you gain new abilities your foes will notice and try even harder to get to the core!  
Charging up that Core to 100% will save the earth and you will WIN the game!! However be sure to protect it,  
as letting those Aliens destroy the Core will spell the end for Earth.
